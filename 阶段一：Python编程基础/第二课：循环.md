一.for 循环与 range()
Python 提供了循环结构，让我们可以通过少量代码重复执行某项任务。

for i in range(5):
    print("Hello Python")

运行结果

Hello Python
Hello Python
Hello Python
Hello Python
Hello Python

for 循环的基本语法

for 变量 in 序列:    #注意这里的冒号,千万不要忘记，有了：才表示循环的开始
    循环执行的代码    #这里的缩进也很重要，一定要缩进，只有缩进了循环才会执行

    for i in range(5):
        print(i)

  结果
  0
  1
  2
  3
  4

  这里有一个有趣的地方，是从0开始，且没有5
  这是因为
  Python 的 range() 默认从 0 开始，并且不包含结束数字。

  二.深入理解range（）
  range() 是 Python 循环中非常常用的工具。
  它主要有三种使用方式。

  1. range(stop)

     for i in range(5):
         print(i)
和上面的代码一样，这里range（5）中的5是指从0开始，到5结束，但不包括5

2. range(start, stop)

for i in range(2, 7):
    print(i)
  这就表示从2开始，到7结束，但不包括7
  输出结果就是
  2
  3
  4
  5
  6

  3. range(start, stop, step)
   for i in range(1, 10, 2):
       print(i)
第一个 1 表示起始值，10 表示结束值， 2表示每一步增加的步长。
输出结果就是
1
3
5
7
9

还可以使用负数作为步长

range() 的规律总结
表达式	产生的数字
range(5)	0、1、2、3、4
range(1, 5)	1、2、3、4
range(1, 10, 2)	1、3、5、7、9
range(5, 0, -1)	5、4、3、2、1

三.while 循环
先看一个生活中的例子：

假设我们编写一个登录系统：
- 用户输入密码。
- 如果密码错误，重新输入。
- 如果密码正确，登录成功，停止输入。
我们并不知道用户需要输入几次才能成功。

这种情况就非常适合使用 while 循环。

1.while 的基本语法
 while 条件:
    循环执行的代码

 执行规则：
1. 首先判断条件是否成立。
2. 如果成立，执行循环内部代码。
3. 执行完毕后，重新判断条件。
4. 如果仍然成立，继续循环。
5. 如果不成立，退出循环。

例如
i = 1
while i <= 5:
    print(i)
    i += 1

print("循环结束")
运行结果：
1
2
3
4
5
循环结束

每次循环，变量 i 都会增加 1。
当 i 变成 6 时，i <= 5 不成立，循环结束。

while 循环必须考虑退出条件。否则会产生死循环，循环内一定要有让变量向循环判断条件进行的语句

四.循环控制与循环嵌套
1.break：终止循环
break 是 Python 中的循环控制语句，它的作用是：
立即结束当前所在的循环，跳出循环体，执行循环后面的代码。

for i in range(1, 11):
    if i == 5:
        break

    print(i)

print("循环结束")

结果

1
2
3
4
循环结束

当 i == 5 时，程序执行 break，整个循环立即结束。
注意：break 后面的 print(i) 也不会执行。

2. break 在 while 中的应用
我们再看一个实际案例：用户登录系统。
假设正确密码为 123456，用户最多有三次输入机会。

password = "123456"

for i in range(3):
    user_input = input("请输入密码：")

    if user_input == password:
        print("登录成功！")
        break
    else:
        print("密码错误！")

请输入密码：111111
密码错误！

请输入密码：222222
密码错误！

请输入密码：123456
登录成功！

break 的核心作用
- 结束当前所在循环。
- 不会仅仅跳过当前一次循环。
- 循环结束后，继续执行循环外面的代码。
- 在嵌套循环中，只会结束它所在的那一层循环。

2. continue 是什么？
continue 的作用是：

结束当前这一次循环，直接进入下一次循环。

注意，它不会结束整个循环。

看一个例子：

for i in range(1, 6):
    if i == 3:
        continue

    print(i)
运行结果：
1
2
4
5

为什么没有输出 3？

因为当 i == 3 时，程序执行了 continue。

它会跳过当前循环中剩余的代码，直接进入下一轮循环。

五.循环嵌套：一个循环里面再放一个循环
1. 什么是循环嵌套？
简单来说：

循环嵌套就是在一个循环内部，再编写另一个循环。

例如：
for i in range(3):

    for j in range(2):

        print(i, j)
运行结果：
0 0
0 1
1 0
1 1
2 0
2 1

为什么会输出六行？

因为：
- 外层循环执行 3 次。
- 每次外层循环，内层循环都完整执行 2 次。
- 因此总执行次数是 3 × 2 = 6 次。
每次外层循环开始时，内层循环都会从头到尾执行一遍。
嵌套循环中的 break 和 continue
这是一个容易混淆的地方。

我们先看：
for i in range(3):

    for j in range(3):

        if j == 1:
            break

        print(i, j)
输出：
0 0
1 0
2 0
为什么？

因为 break 位于内层循环中，所以它只结束内层循环。

外层循环仍然会继续执行。

再看
 for i in range(3):

    for j in range(3):

        if j == 1:
            continue

        print(i, j)
输出
0 0
0 2
1 0
1 2
2 0
2 2
