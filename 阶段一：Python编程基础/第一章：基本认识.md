一.Python 到底是什么？

Python 是一种编程语言。我们可以通过它告诉计算机应该执行什么任务。

例如，我们希望计算机完成以下任务：
1. 读取一个 PDF 文件。
2. 提取 PDF 中的文字。
3. 将文字发送给 AI 模型。
4. 获取 AI 模型的回答。
5. 将回答展示给用户。
这些操作都可以使用 Python 编写程序实现。

为什么我们选择 Python？

主要有三个原因：
- 语法相对简单，适合零基础学习。
- 拥有丰富的人工智能开发工具和第三方库。
- LangChain、FastAPI、ChromaDB 等我们后面会用到的工具都支持 Python。
你可以先这样理解：

Python 是我们开发整个 AI 知识库系统的主要工具。
文件名以.py为结尾

下面我们来写第一段代码：

print("Hello World!")
print("欢迎来到 Python 的世界！")
print("我的目标是开发一个 AI 智能知识库问答系统！")

输出结果：

Hello World!
欢迎来到 Python 的世界！
我的目标是开发一个 AI 智能知识库问答系统！

初步认识了代码，接下来认识虚拟环境

这一部分先理解概念。
以后我们会安装很多第三方库，例如：
- FastAPI：开发后端接口。
- LangChain：构建 AI 应用。
- ChromaDB：保存和检索文本向量。
- PyMuPDF：读取 PDF 文件。
如果所有项目都共用一套 Python 软件包，可能产生版本冲突。
因此，我们使用虚拟环境（Virtual Environment）。

创建自己的虚拟环境
命令如下

python -m venv .venv

在终端激活环境

.venv\Scripts\Activate.ps1

激活成功后，通常在终端前面会出现

(.venv)

这表示我们已经进入项目自己的 Python 环境。

二.Python变量，数据类型与基本运算
1.变量
我们先思考一个问题：

假设我们正在开发一个 AI 知识库系统，用户上传了一份文件：
Python学习笔记.pdf
我们希望程序记住这个文件的名称，以便后续读取。
应该怎么办？
最简单的方法就是使用变量。
例如：

filename = "Python学习笔记.pdf"
print(filename)

这里的 filename 就是一个变量。
你可以把变量理解为一个带有名字的存储位置，我们可以通过名字访问其中保存的数据。

定义一个变量非常简单
就像这样

name = "张三"
age = 20
height = 1.75
is_student = True

只需要用
变量名称=数据 
的形式

我们发现Python的变量定义很简洁，在学习C语言的时候，我们需要提前声明

int age = 20;
float height = 1.75;

但Python不需要声明类型
这就是 Python 的一个特点：动态类型。
变量不需要预先声明固定的数据类型，Python 会根据赋值自动确定对象的类型。

变量命名规则
Python 对变量名称有一定要求。

1name = "张三"       # 错误：不能以数字开头
user-age = 20       # 错误：不能使用减号
class = "学生"       # 错误：class 是 Python 关键字

这里还有一个重要的命名习惯：
Python 通常使用小写字母和下划线命名变量，这种风格叫做 snake_case（蛇形命名法）。
在Python中，print可以输出多个内容，中间使用 ， 分隔。逗号会让 print() 默认在输出内容之间添加空格
print("用户名：", username)

三.Python的数据类型

Python 常见的四种基础数据类型

① int：整数类型
保存没有小数部分的整数。
例如：10、20、-5、1000

② float：浮点数类型  
保存带有小数部分的数字。
例如：3.14、1.75、-0.5
需要注意：浮点数在计算机中采用近似表示，因此某些计算可能出现非常细微的精度误差。

③ str：字符串类型
保存文字、字符等文本数据。
例如："Hello"、"Python"、"你好"
字符串必须使用引号包围
下面两种写法都可以：

name = "Python"
name = 'Python'

还可以使用三引号

content = """
这是第一行内容。
这是第二行内容。
这是第三行内容。
"""
为什么需要三引号？
因为在知识库项目中，我们经常需要读取多行文本。
例如一份 PDF 文档提取出来的内容可能有几千行，三引号可以方便地表示多行字符串

④ bool：布尔类型
表示逻辑判断的结果。
只有两个值：True 和 False
注意首字母必须大写。
布尔类型经常用于判断

is_login = True
if is_login:
    print("欢迎进入知识库系统")
if在后续将讲到

既然Python能自己识别数据类型，那我们应如何查看呢？
使用 type（）查看
例如

age = 20
height = 1.75
name = "Tom"
is_student = True
print(type(age))
print(type(height))
print(type(name))
print(type(is_student))

运行结果

<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>

四.数据类型转换
这一部分非常重要。
为什么？
因为不同类型的数据不能随意进行所有运算。

age = "20"
print(age + 5)

这段代码就会报错
"20" 是字符串。
5 是整数。
Python 不允许直接把字符串和整数相加
我们需要进行数据类型转换

int()：转换为整数
a = "100"
b = int(a)
print(b)
print(type(b))

int(a)就是将变量a转化成整数
同理，其他的类型转化也是如此 
类型名（变量）
注意bool值的转化

常见转换规则：
原始数据	转换结果
bool(1)	True
bool(0)	False
bool("")	False
bool("Hello")	True
bool([])	False

非空字符串，即使内容是 "False"，转换成布尔值仍然是 True
print(bool("False"))
结果
True
因为 Python 判断的是字符串是否为空，而不是字符串表达的意思

五.input函数
它可以接收用户输入的数据。

birth_year = input("请输入你的出生年份：")
birth_year = int(birth_year)
age = 2026 - birth_year
print("你的年龄大约是：", age)

注意：
input() 返回的数据默认是字符串。
所以我们必须使用：
int(birth_year)
转换成整数，才能进行减法运算。
这里的 2026 只是本案例的年份，实际程序以后可以自动获取当前年份。

六.基本运算符
现在进入数学运算部分。
Python 支持多种运算符，其中最基础的是算术运算符。
1. 加法、减法、乘法、除法
    +     -    *     /

Python 中的 / 除法，即使能够整除，结果通常也是浮点数

整除运算符：//
这样输出的结果就是一个整数了，比如输入10//3
结果 3
这里也是向下取整
注意，对于负数，// 也是向负无穷方向取整

取余运算%

print（10%3）

输出 1

幂运算**
例如 print（2**3）
就是输出8

六.字符串运算
字符串是我们未来 AI 知识库系统中最重要的数据类型之一。
因为用户提问、文档内容、AI 回复，本质上都涉及文本处理。
1. 字符串拼接
例如：

first_name = "张"
last_name = "三"
full_name = first_name + last_name  这里的 + 不再是数学加法，而是字符串拼接
print(full_name)

输出 张三

2. 字符串重复
Python 允许使用 * 重复字符串。

text = "Python "
print(text * 3)

Python Python Python

3. f-string：格式化字符串
这是一个非常重要的知识点。
我们经常需要将变量和文字组合在一起。
例如：

username = "Tom"
age = 22
print(f"用户姓名：{username}，年龄：{age}")

这里输出

用户姓名：Tom，年龄：22

f"..."叫做f-string。
变量需要放在大括号 {} 中。
再看一个未来项目中的例子：

filename = "Python笔记.pdf"
question = "Python是什么？"
print(f"正在从文件 {filename} 中查找问题：{question}")

这样输出不会有空格产生，输出更自然

七.比较运算符与逻辑运算符
这部分为后面的条件判断做准备。

1. 比较运算符
比较运算符用于比较两个数据，返回的结果是布尔值。
运算符	含义	示例	结果
==	等于	5 == 5	True
!=	不等于	5 != 3	True
>	大于	5 > 3	True
<	小于	5 < 3	False
>=	大于等于	5 >= 5	True
<=	小于等于	3 <= 5	True

2. 逻辑运算符
Python 有三个常见的逻辑运算符：
- and：并且。
- or：或者。
- not：取反。

例如

age = 20
is_vip = True
print(age >= 18 and is_vip)

输出结果 True
还是这个代码，假如
print(not is_vip)
结果就是False

八.注释符  #
Python用#来写注释，#后面的内容不会执行，用来解释代码

九. if elif else 多条件判断
先看代码实例

score = 85
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")

我们想判断一个学生是否及格
运行结果就是 良好 
这里有一个非常重要的知识点：
Python 从上到下依次判断，遇到第一个成立的条件后，就会执行对应代码，然后跳过整个条件判断结构。
因此，条件的顺序非常重要。
假如我们这样写

score = 95
if score >= 60:
    print("及格")
elif score >= 90:
    print("优秀")

运行结果就是 及格，但很显然这是优秀的成绩
