这一课非常重要。前面第三课，我们已经用 names 和 scores 两个列表完成了一个学生成绩管理系统。

但你可能已经发现：一个学生的信息被拆分在两个列表中管理，并不是特别方便。

例如：
names = ["张三", "李四", "王五"]
scores = [85, 92, 76]
张三的姓名在 names[0]，成绩在 scores[0]。如果删除或修改时下标没有同步，就可能造成数据错乱。

今天我们将学习四种 Python 核心数据结构，并逐步把学生成绩管理系统升级成更合理的版本。
第一部分：列表（list）
1. 什么是列表？
列表可以理解为一个能够存放多个数据的容器。

例如，一个班级有五名学生：

students = ["张三", "李四", "王五", "赵六", "钱七"]

这里的 students 就是一个列表。

列表具有四个重要特点：
1. 有序：每个元素都有自己的位置。
2. 可修改：可以增加、删除、修改元素。
3. 允许重复：可以存在相同的元素。
4. 可以存储不同类型的数据。
例如 data = ["张三", 18, 85.5, True]
这里存放了多种类型的数据，有整形浮点型字符串等
2. 如何创建列表？
 # 方法一：直接创建
scores = [85, 92, 76, 88]

# 方法二：创建空列表
names = []

# 方法三：使用 list()
numbers = list((1, 2, 3))

3. 列表的索引
列表中的每个元素都有一个编号，这个编号叫作索引（index）。索引都是从零开始
有一个小知识点，python中有负索引
students = ["张三", "李四", "王五"]

print(students[0])   # 张三
print(students[1])   # 李四
print(students[2])   # 王五

print(students[-1])  # 王五
print(students[-2])  # 李四

正索引从右向左，且是以0开始。
但负索引是从左向右，最左边的元素是-1，从左向右递减
如果访问不存在的索引：就会产生 IndexError，
4. 列表的增删改查
这是列表最常用的操作。

（1）增加元素
students = ["张三", "李四"]

# 在列表末尾添加
students.append("王五")

# 在指定位置插入
students.insert(1, "赵六")

print(students)

上节我们介绍了append（）是在列表结尾加入元素
而insert（i，X）就是指
  在索引 i 处插入 x
extend（iterable）就是将一个可迭代对象的数据逐个加入列表中
a = [1, 2]
b = [3, 4]

a.extend(b)

print(a)  # [1, 2, 3, 4]
（2）删除元素
students = ["张三", "李四", "王五"]

# 按值删除
students.remove("李四")

# 按索引删除
students.pop(0)

# 删除指定索引
del students[0]

print(students)

这三个操作需要区分：
- remove(value)：删除第一个匹配的值。
- pop(index)：删除并返回指定位置的元素；不传索引时删除最后一个。
- del：删除指定位置的元素，也可以删除整个变量。
（3）修改元素
students = ["张三", "李四", "王五"]

students[1] = "赵六"

print(students)
输出
['张三', '赵六', '王五']

修改的方式很纯粹，只需要找到对应的元素索引然后对他赋值即可
（4）查询元素
students = ["张三", "李四", "王五"]

print("李四" in students)       # True
print("赵六" in students)       # False

print(students.index("李四"))   # 1
print(students.count("张三"))   # 1

其中：
- in：判断元素是否存在。
- index()：查找元素第一次出现的位置。
- count()：统计元素出现次数。

5. 列表切片
切片（slicing）可以一次获取列表中的一部分元素。

语法：
列表名[start:end:step]
start为起始位置，end为结束位置，step代表步长
这里也是只包含start，不包含end，

numbers = [10, 20, 30, 40, 50, 60]

print(numbers[1:4])   # [20, 30, 40]
print(numbers[:3])    # [10, 20, 30]
print(numbers[2:])    # [30, 40, 50, 60]
print(numbers[::2])   # [10, 30, 50]
print(numbers[::-1])  # [60, 50, 40, 30, 20, 10]

[::-1] 是一个非常实用的技巧，可以反转列表。
其中有的参数也可以省略，省略第一位就是从0开始；
省略第二位就是一直取到列表结尾，若全省略就相当于复制整个列表，省略第三位就默认步长为1
注意
a=numbers
b=numbers[:]
这是两种截然不同的含义
其中a是与原列表一摸一样的
而b虽然数据一样，但其实是一份新列表，如果我们让a[0]改变，那b中的值是不会发生变化的

这里要注意区分索引和切片
numbers[1]   这是索引，指向列表中的第二个元素，他是int形
numbers[1:2] 这是切片，虽然他只有一个值且和上面的一样，但他是列表
这两种的数据类型不一样，一定要注意区分。

切片和负数结合也有许多常用的小技巧，例如刚刚的列表逆序，意味着从右向左，每次移动一个位置

常见的切片用法就是修改列表中的某一段元素
例如
number=[1,2,3,4,5]
number[1:4]=[20,30]
print(number)

得到结果

1，20，30，5

这个切片中有3个元素但我们只替换了2个值，所以第3位默认为0

在指定位置插入元素
num=[1,2,3]
num[1:1]=[100,200]
print(num)

得到结果

1，100，200，3
因为起始和结束位置相同，所以没有替换任何内容，只是插进去元素

6. 遍历列表
我们之前学习过 for 循环，现在把它和列表结合起来。
scores = [85, 92, 76, 88]

for score in scores:
    print(score)

如果需要同时得到索引和值，可以使用 enumerate()：

students = ["张三", "李四", "王五"]

for index, name in enumerate(students):
    print(index, name)

7. 列表排序
scores = [85, 92, 76, 88]

# 升序排列
scores.sort()
print(scores)  # [76, 85, 88, 92]

# 降序排列
scores.sort(reverse=True)
print(scores)  # [92, 88, 85, 76]

还有一个常见函数：
scores = [85, 92, 76, 88]

new_scores = sorted(scores)

print(new_scores)  # [76, 85, 88, 92]
print(scores)      # [85, 92, 76, 88]

区别：
- sort()：直接修改原列表。
- sorted()：返回一个新列表，不改变原列表。

在sort降序排列中我们需要认识一个参数reverse，它是一个布尔值，默认是False
reverse=False  代表升序
reverse=true   代表降序

a.sort()                    # 升序
a.sort(reverse=True)        # 降序

sorted(a)                   # 升序
sorted(a, reverse=True)     # 降序

重点 key 关键字
key 可以理解为：告诉 Python 按照什么标准进行排序。
1.按照字符串长度排序
words=["a","abc","mj","jordan",""kanyewest","cole","drake"]
words.sort(key=len)
print(words)

得到结果就会是按照字符串长度来排序的结果
注意这里不需要写len(),因为我们传入的是len函数本身
