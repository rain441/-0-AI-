第一部分：列表（list）
1. 什么是列表？
列表可以理解为一个能够存放多个数据的容器。

例如，一个班级有五名学生：

students = ["张三", "李四", "王五", "赵六", "钱七"]

这里的 students 就是一个列表。

列表具有四个重要特点：
1. 有序：每个元素都有自己的位置。
2. 可修改：可以增加、删除、修改元素。
3. 允许重复：可以存在相同的元素。
4. 可以存储不同类型的数据。
例如 data = ["张三", 18, 85.5, True]
这里存放了多种类型的数据，有整形浮点型字符串等
2. 如何创建列表？
 # 方法一：直接创建
scores = [85, 92, 76, 88]

# 方法二：创建空列表
names = []

# 方法三：使用 list()
numbers = list((1, 2, 3))

3. 列表的索引
列表中的每个元素都有一个编号，这个编号叫作索引（index）。索引都是从零开始
有一个小知识点，python中有负索引
students = ["张三", "李四", "王五"]

print(students[0])   # 张三
print(students[1])   # 李四
print(students[2])   # 王五

print(students[-1])  # 王五
print(students[-2])  # 李四

正索引从右向左，且是以0开始。
但负索引是从左向右，最左边的元素是-1，从左向右递减
如果访问不存在的索引：就会产生 IndexError，
4. 列表的增删改查
这是列表最常用的操作。

（1）增加元素
students = ["张三", "李四"]

# 在列表末尾添加
students.append("王五")

# 在指定位置插入
students.insert(1, "赵六")

print(students)

上节我们介绍了append（）是在列表结尾加入元素
而insert（i，X）就是指
  在索引 i 处插入 x
extend（iterable）就是将一个可迭代对象的数据逐个加入列表中
a = [1, 2]
b = [3, 4]

a.extend(b)

print(a)  # [1, 2, 3, 4]
（2）删除元素
students = ["张三", "李四", "王五"]

# 按值删除
students.remove("李四")

# 按索引删除
students.pop(0)

# 删除指定索引
del students[0]

print(students)

这三个操作需要区分：
- remove(value)：删除第一个匹配的值。
- pop(index)：删除并返回指定位置的元素；不传索引时删除最后一个。
- del：删除指定位置的元素，也可以删除整个变量。
（3）修改元素
students = ["张三", "李四", "王五"]

students[1] = "赵六"

print(students)
输出
['张三', '赵六', '王五']

修改的方式很纯粹，只需要找到对应的元素索引然后对他赋值即可
（4）查询元素
students = ["张三", "李四", "王五"]

print("李四" in students)       # True
print("赵六" in students)       # False

print(students.index("李四"))   # 1
print(students.count("张三"))   # 1

其中：
- in：判断元素是否存在。
- index()：查找元素第一次出现的位置。
- count()：统计元素出现次数。

5. 列表切片
切片（slicing）可以一次获取列表中的一部分元素。

语法：
列表名[start:end:step]
start为起始位置，end为结束位置，step代表步长
这里也是只包含start，不包含end，

print(numbers[1:4])   # [20, 30, 40]
print(numbers[:3])    # [10, 20, 30]
print(numbers[2:])    # [30, 40, 50, 60]
print(numbers[::2])   # [10, 30, 50]
print(numbers[::-1])  # [60, 50, 40, 30, 20, 10]

[::-1] 是一个非常实用的技巧，可以反转列表。
其中有的参数也可以省略，省略第一位就是从0开始；
省略第二位就是一直取到列表结尾，若全省略就相当于复制整个列表，省略第三位就默认步长为1
注意

b=numbers[:]
这是两种截然不同的含义
其中a是与原列表一摸一样的
而b虽然数据一样，但其实是一份新列表，如果我们让a[0]改变，那b中的值是不会发生变化的

这里要注意区分索引和切片
numbers[1]   这是索引，指向列表中的第二个元素，他是int形
numbers[1:2] 这是切片，虽然他只有一个值且和上面的一样，但他是列表
这两种的数据类型不一样，一定要注意区分。

切片和负数结合也有许多常用的小技巧，例如刚刚的列表逆序，意味着从右向左，每次移动一个位置

常见的切片用法就是修改列表中的某一段元素
例如

得到结果

1，20，30，5

这个切片中有3个元素但我们只替换了2个值，所以第3位默认为0

在指定位置插入元素

因为abs（）可以获取数字绝对值

二.元组（tuple）
1. 什么是元组？
元组和列表非常相似，也可以存储多个元素。

1. 什么是集合？
集合是一种用于保存不重复元素的数据结构。

例如，一个班级有这些选课记录：

重复的元素会被自动去除。

集合有三个重要特点：
1. 元素不重复。
2. 不支持通过索引访问元素。
3. 集合是无序的，不应该依赖其显示顺序。
2. 如何创建集合？
集合使用大括号 {}，但和字典不同，它只有元素，没有键值对。
numbers = {1, 2, 3, 4}
print(numbers)
创建空集合时要特别注意：
a = {}       # 空字典

# 删除元素，不存在时会报错

print("李四" in students)
还有一个常用方法

它会清空集合。
4. 集合的运算
集合的强大之处在于可以直接进行数学意义上的集合运算。
进行集合之间的交集并集差集
假设：
python_students = {"张三", "李四", "王五"}
java_students = {"李四", "王五", "赵六"}
例如我想求这两门课程集合的运算
python_students = {"张三", "李四", "王五"}

# 交集
print(python_students & java_students)

# 并集
print(python_students | java_students)

运算符	名称	含义
&	交集	两个集合都存在
\|	并集	任意一个集合存在
-	差集	在左侧集合但不在右侧集合
^	对称差集	只在其中一个集合存在

注意：集合中的元素必须是可哈希的。常见的整数、字符串、元组可以作为集合元素，但列表和字典不能直接放进集合。
集合中的元素必须可哈希（Hashable）」是 Python 集合（Set）和字典（Dictionary）背后的一个核心知识点。
很多初学者知道 set 不能存储列表，却不知道为什么。今天我们从基础原理开始，把它彻底讲清楚。
一、首先，什么是哈希（Hash）？
你可以先把哈希理解成：
Python 通过一个哈希函数，把一个对象转换成一个整数，这个整数就是它的哈希值（Hash Value）。
例如：
a = "Python"

print(hash(a))a = "Python"

print(hash(a))
运行后会得到一个整数，例如：12345678
注意：这里的数字只是示意。实际哈希值由 Python 运行环境决定，不同运行进程中某些类型的哈希值可能不同。
我们再看一个例子：
print(hash(100))
print(hash("hello"))
print(hash(3.14))
它们都会得到对应的整数哈希值。
你可以把哈希函数想象成一个转换器：
为什么需要哈希值？
因为 Python 的集合和字典需要快速定位元素。
例如，你有一个包含10000个元素的集合，想判断其中是否存在某个元素。
如果每次都从头到尾逐个比较，会比较慢。
哈希值可以帮助 Python 快速找到可能存放该元素的位置。
这就是哈希的主要作用之一。
二、什么叫可哈希（Hashable）？
理解了哈希值，我们就可以解释可哈希了。
一个对象如果满足 Python 的哈希要求，就称它为可哈希对象。
主要需要满足两个条件：
它有一个可用的哈希值，能够通过 hash() 获取。
在它的生命周期内，哈希值必须保持不变。
还有一个重要规则：
如果两个对象相等（a == b），那他们的哈希值必须相等
注意反过来不一定成立：两个不同的对象也可能具有相同的哈希值，这叫作哈希冲突。
三、哪些数据类型可以哈希，哪些不可以？

元组虽然通常是可哈希的，但如果里面包含不可哈希对象，它也不能哈希。
四、为什么列表不能放入集合？
现在我们来理解背后的原因。
先看一个例子：
numbers = {1, 2, 3}

numbers.add(4)

print(numbers)
这可以正常运行
但是
numbers = {1, 2, 3}

numbers.add([4, 5])
就会报错
这是因为列表是可变对象（Mutable Object）。
例如
a = [1, 2, 3]

a.append(4)

print(a)
列表可以随时修改。
假设列表被允许放进集合：
a = [1, 2, 3]
假设它此时的哈希值是100。
Python 根据哈希值100，把它放到了集合中的某个位置。
但后来你修改了列表
a.append（4）
列表就变成了
a=[1,2,3,4]
如果它的哈希值发生变化，那么 Python 就可能无法根据新的哈希值找到之前存储的位置。
这会破坏集合的查找机制。
因此，Python 不允许普通列表作为集合元素。
同理可得，字典的key也必须是可哈希的，因为需要通过key来快速寻找值，如果key可以随意改变，字典就无法快速定位数据

如何选择？
- 需要保存一组可以变化的数据：用列表。
- 需要保存一组固定的数据：用元组。
- 需要通过某个标识查找对应信息：用字典。
- 需要去重或者比较不同群体：用集合。
