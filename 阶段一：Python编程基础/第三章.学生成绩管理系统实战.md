一、项目目标与功能设计
我们准备开发一个简单的学生成绩管理系统。

假设有一个班级，需要管理多名学生的姓名和成绩。

系统需要实现以下功能：
编号	功能	说明
1	添加学生	输入姓名和成绩
2	查看学生	显示全部学生信息
3	查询学生	根据姓名查找成绩
4	统计成绩	计算平均分、最高分、最低分
5	判断等级	根据成绩判断优秀、良好、及格或不及格
6	删除学生	根据姓名删除学生记录
0	退出系统	结束程序

我们最终希望实现这样的交互效果：
========== 学生成绩管理系统 ==========

1. 添加学生
2. 查看所有学生
3. 查询学生成绩
4. 统计成绩信息
5. 删除学生
0. 退出系统

请输入功能编号：

用户输入不同编号，程序就执行不同的功能。

扩充知识：列表
列表是 Python 中非常重要的数据结构，能够在一个变量中保存多个数据。

names = ["张三", "李四", "王五"]

print(names)

输出

['张三', '李四', '王五']

很类似于C语言中的数组

列表的特点：
- 使用 [] 创建。
- 多个元素之间使用逗号分隔。
- 可以保存多个数据。
- 可以通过下标访问元素，下标从 0 开始。

print(names[0])  # 张三
print(names[1])  # 李四
print(names[2])  # 王五

二.设计程序主菜单
接下来，我们使用 while 循环，让系统能够持续运行。
names = []
scores = []

while True:

    print("\n========== 学生成绩管理系统 ==========")
    print("1. 添加学生")
    print("2. 查看所有学生")
    print("3. 查询学生成绩")
    print("4. 统计成绩信息")
    print("5. 删除学生")
    print("0. 退出系统")

    choice = input("请输入功能编号：")

    if choice == "0":
        print("系统已退出！")
        break

    elif choice == "1":
        print("执行添加学生功能")

    elif choice == "2":
        print("执行查看学生功能")

    elif choice == "3":
        print("执行查询学生功能")

    elif choice == "4":
        print("执行成绩统计功能")

    elif choice == "5":
        print("执行删除学生功能")

    else:
        print("输入错误，请重新选择！")
 1. 为什么使用 while True？
表示创建一个持续运行的循环。
只有遇到 break，程序才会退出。
2.为什么使用 input()？
choice = input("请输入功能编号：")
这里需要特别注意：
input() 返回的是字符串。因此
choice == "1"
而不是
choice == 1
3.为什么使用 break？
当用户输入 0 时：程序直接跳出 while 循环，结束系统。

第五阶段：实现查询学生成绩
现在我们需要让用户输入一个姓名，程序自动查找对应的成绩。

这里将使用：
- for 循环。
- if 条件判断。
- break。
- 布尔变量。
代码：
elif choice == "3":

    search_name = input("请输入要查询的学生姓名：")

    found = False

    for i in range(len(names)):

        if names[i] == search_name:

            print("查询成功！")
            print("姓名：", names[i])
            print("成绩：", scores[i])

            found = True
            break

    if found == False:
        print("没有找到该学生！")
1. found = False 是什么意思？
它表示暂时没有找到学生。
如果循环中找到对应学生：
found = True
就把状态修改为已经找到。
2. 为什么使用 break？
   if names[i] == search_name:
    ...
    break
因为一旦找到学生，就不需要继续遍历剩余数据了。

这正是 break 的实际应用场景。
3. 为什么循环结束后还要判断 found？
如果遍历完整个列表都没有找到对应姓名，那么 found 仍然是 False。

这时程序就会输出：
没有找到该学生！
第六阶段：实现成绩统计功能
现在进入一个非常实用的功能：成绩统计。

我们希望系统能够自动计算：
1. 学生人数。
2. 平均成绩。
3. 最高成绩。
4. 最低成绩。

代码

elif choice == "4":

    if len(scores) == 0:
        print("暂无成绩数据！")

    else:
        total = 0

        for score in scores:
            total += score

        average = total / len(scores)

        highest = max(scores)
        lowest = min(scores)

        print("学生人数：", len(scores))
        print("平均成绩：", average)
        print("最高成绩：", highest)
        print("最低成绩：", lowest)
这里我们又认识了三个非常实用的 Python 内置函数。
函数	作用	示例

max()	求最大值	max([80,90]) → 90
min()	求最小值	min([80,90]) → 80

这里再补充一些有关for循环的小知识，我们更准确可以把for循环写成
for 变量 in 可迭代对象:
    循环体
这里一一拆解
变量 在这里是用于接收每次遍历得到的元素的
in   表示从某个对象中依次取出元素
可迭代对象  是指这个内容可以被依次遍历，常见的就有列表，变量就是来接受他每次呗遍历的值
核心理解：每次循环，Python 都会从可迭代对象中取出一个元素，赋值给循环变量，然后执行循环体。

for循环还可以遍历哪些类型？

第七阶段：实现删除学生功能
最后，我们实现删除功能。
要求：
用户输入姓名，程序找到对应学生，然后同时删除他的姓名和成绩。

代码：
elif choice == "5":

    delete_name = input("请输入要删除的学生姓名：")

    found = False

    for i in range(len(names)):

        if names[i] == delete_name:

            names.pop(i)
            scores.pop(i)

            print("学生删除成功！")

            found = True
            break

    if found == False:
        print("没有找到该学生！")
  这里需要认识一个新的列表方法：pop()。
  1. pop() 的作用
pop() 可以根据下标删除列表中的元素。
例如：
names = ["张三", "李四", "王五"]

names.pop(1)

print(names)

输出
['张三', '王五']
因为下标为 1 的元素是李四，所以它被删除了。
